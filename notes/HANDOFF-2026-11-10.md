# Utopia handoff — 2026-11-10

This is a continuation handoff, not a completion claim. The project is an in-progress TypeScript / Canvas 2D recreation that reads the player's own WHDLoad 1.2 (0757) files. Nothing here is committed; see [Repository state](#10-repository-state). It supersedes [HANDOFF-2026-11-07.md](HANDOFF-2026-11-07.md) where they differ (the save version is now 10, not 9).

Read first: [AGENTS.md](../AGENTS.md) (project rules), [README.md](../README.md) (feature inventory), [ARCHITECTURE.md](ARCHITECTURE.md) (layers and evidence levels), [notes/README.md](README.md).

## 1. Objective and supported scope

- **Goal:** a standalone engine that runs from game files the player supplies. ScummVM is an analogy only. No original disks, assets or executable data are bundled or committed; the engine reads `original/` locally at run time.
- **Supported input:** WHDLoad 1.2 (0757) file structure only. `Disk.1` and `Disk.2` are required and byte-validated; `Disk.4` (save seed) is optional. ADF / HDF / IPF mounting is **not** implemented, and no other release is claimed.
- **Not claimed:** full gameplay fidelity, audio waveform parity, full save continuation, or hardware-exact timing.

## 2. Native save and Disk.4 limits

**Native remake save (`src/game/save-session.ts`, `save.ts`):** format version **10** (`SESSION_VERSION = 10`). Stored in browser localStorage slots 0–7. Version 10 adds the `$156A9` bit-5 blast mark; versions 2–9 migrate with it clear. It stores runtime entities, the exact main-loop phase and pending modal-return pass, all 30 fixed effect slots (with holes) and the raw `+$16` pointer of every enemy fixed slot, free slots included. Field list and migration rules: [formats/remake-save.md](formats/remake-save.md).

**Disk.4 (experimental, not a restore claim):**

- `Game.activateDisk4()` reads the saved scenario-disk id (`$1453E`) and scenario index (`$135C2`). It applies the traced `$875C`–`$87DA` reset and clears the 30 effect slots (`$88DC`–`$88E6`). Map comparison is advisory; an explicit recovery choice exists only for an invalid saved index.
- Headless enemy and ship continuation (`prepareDisk4HeadlessEnemies()`) adopts exact fixed slots and rosters inertly, all-or-error. It does not spawn, initialise, consume RNG or write buffers; movement advances only through explicit `pass(clock)` calls. `frame()` is a legacy no-op.
- **Refused or unsupported:** crushers with counter > 7 or animation above the `$12D60` table maximum; missile modes other than 1/2/4; lift above `$7F`; non-playable `+$14` pointers; mismatching `$1429E` count.
- **Save from a Disk.4 session is disabled** by the native-save policy (`SAVE GAME (OFF: DISK.4 SESSION)`). No Disk.4 export, write-through, re-packing or roundtrip exists.
- **Still open:** original post-load initialisation, RNG restoration, the `$802C` exit-handler behaviour, restored ship landing (static trace and synthetic only), robust scenario identification for edited maps.
- Details: [formats/game-proper.md](formats/game-proper.md) (Disk.4 sections), [formats/ship-control.md](formats/ship-control.md) §5c–5e, [formats/enemies.md](formats/enemies.md) §3a.

## 4. Evidence levels

| Level | Meaning in this repo | Examples |
|---|---|---|
| **STATIC** (VERIFIED from code / HYPOTHESIS) | Traced from the Disk.1 disassembly or the raw image. Not observed running. | Draw-list `$333A`/`$4860`, blink poll model, date/money/QoL positions, top-bar template |
| **SYNTHETIC** | Headless tests with built fixtures or local tables. Does not prove the original produces the same output. | `test/disk4-*.mjs`, `test/sfx.mjs`, `test/audio-ownership.mjs`, `test/overview.mjs` |
| **OBSERVED / MEASURED (original)** | A Copperline 1.0.1 run or the player's own capture, checked against the remake. Limited to the captured state. | Title/language pixels, one map frame, tank route, November production transition, one RAM-staged invasion, blink and countdown timing |

Rules that matter here: a comparator pass covers only its captured state; no comparator covers ordinary campaign play. Static tracing and synthetic tests never establish fidelity by themselves.

## 6. Measurements

**A1200 overview blink** (screens.md "Blink cadence"; Copperline 1.0.1, 2026-11-10, one run per configuration):

- A1200 / 68020 / AGA / PAL: entry at VBL 34; first blink at VBL 42; phase toggle at VBL 44; steady period **10 VBLs**. Matches the model's 10-update figure.
- A600 / 68000 / PAL (2 MiB chip): entry at VBL 81; first blink at VBL 94; steady period **14 VBLs**. The model predicts 9–11 here, so it disagrees. The likely cause (chip-RAM / DMA contention with the five-plane overview on a 68000) is a hypothesis, not measured.
- Model constants (`src/game/screens/overview.ts`: 723 idle passes per update, 196 clocks per pass) were **not changed**. Which machine the remake should model is an open decision.

**Disk-menu info-line lifetime** (`INFO_LIFETIME_FRAMES = 53` in `src/game/disk-menu.ts`; screens.md, Measured countdown):

- A1200 / 68020 / AGA / PAL: 20,000 passes of `$8CB0`, measured for the effects and music messages. Lifetime **53 VBLs** (3,751,993 CCK, about 52.9 fields) in both runs.
- The value is CPU-dependent. No 68000 measurement of this countdown exists.

## 7. Map and UI pixel status

Map-layer pixels and the mode icon are exact on one frame, as above. The rest of the UI is only partly matched.

**Top bar (rows 0–23; game-text.md §8, map-rendering.md §11):**

- Money at x 110, date at x 8, quality of life at x 224, title word at x 182. The template positions and draw order come from static tracing.
- The capture shows 03/07/2090, 506040 GR and 44 % DOL. Unstaged, the remake shows 28/06/2090 and a still-queued first day tick, and the top bar differs in 82 pixels (x 8..255, y 2..7). With explicit visual staging (`UTOPIA_MAP_TOPBAR=staged`: `A.day`/`A.month`/`A.year`/`A.money`/`A.qualityOfLife` written to the capture's values, then one initial frame, no pass or tick), the top-bar crop (rows 0..23, full width, 7,680 pixels) matches **exactly**: 0 mismatches. This is one-frame pixel alignment of the staged state, not a comparison of simulation history; the date and money were not reached by the remake's own simulation.
- The title-word flash period in real time is HYPOTHESIS (the original's pass length is not measured).

**Other UI limits:**

- Demolish mode icon (`$3A`): no capture.
- Build mode: whether leftover select-icon pixels show through transparent parts of the building at (272, 52) in the original is not established.
- Log panel: a fresh scene still shows the picture, because `$866E` sets `$14634 = $FFFF` and the main loop does not clear it. The remake fills the panel only after a log clear. See [formats/game-state.md](formats/game-state.md) §3.10.
- Overview pointer and hover: browser-vs-original hotspot alignment is open ([formats/map-rendering.md](formats/map-rendering.md) §8, §10).
- Pressed-button flip colour effect on the palette: not compared.

## 8. Unresolved gaps

1. **Live `$15668` text-context init not reached.** Two Copperline runs on 2026-11-10 (both recorded in [formats/screens-misc.md](formats/screens-misc.md)) saw the record zero, then `$CCCC` from a fill loop. The disk values (x 8, y 39, width 240) were not observed in RAM before the intro language stage. `$E770` / `$E7EC` were never hit. The remake reads the disk values statically. There is also an unresolved discrepancy in the language poll address (`$786F4` vs `$786DC`, see screens-misc.md). The remaining steps are a read of `$15668`..`$1566F` at the first `$E770`, and a clean language choice.
2. **Gameplay pixel parity:** only one map frame, the title and the language picture. No sprite-artwork, draw-order, credit-roll or menu pixel comparison beyond that.
3. **Audio parity:** channel ownership is STATIC plus SYNTHETIC (`src/audio/sfx-scheduler.ts`). The A1200 LED filter is an approximation. No waveform, Paula-level or timing capture exists.
4. **Full save continuation and Disk.4:** no write-through, export or roundtrip; RNG restoration and post-load initialisation incomplete (section 2).
5. **Hardware-specific timing:** CPU-dependent constants (overview blink, info lifetime, the main-loop pass cadence) are measured on one or two configurations, not on a known original machine.
6. **RNG:** `Sim.roll()` still uses the remake generator. The isolated `$2DCC` model is not wired into the simulation; its seed provenance and caller D0 / CIA TOD evidence are incomplete ([formats/original-rng-callers.md](formats/original-rng-callers.md)).
7. **Invasion comparator:** the staged baseline's object count is inconsistent with its records (section 5).
